# Библиотека заклинаний D&D 5e 2014

Здесь собраны **522 заклинания** из индексного снимка **официального (не Homebrew) раздела D&D 5e 2014** сайта [dnd.su](https://5e14.dnd.su/spells/), включая PHB и официальные дополнения. Это снимок каталога, поэтому новые карточки, добавленные на сам сайт позже, могут отсутствовать.

Карточки содержат название, круг, базовые классы (если они отмечены источником) и прямую ссылку на dnd.su. Полное описание остаётся на сайте-источнике. Некоторые заклинания доступны только через подклассы/особые источники, поэтому поле классов у них может быть пустым.

## Добавление в лист персонажа

Открой лист Риас либо тестового персонажа, нажми **Добавить заклинание**, найди карточку и выбери её. **Удалить заклинание** снимает выбранную карточку из списка персонажа, не удаляя её из библиотеки.

Для добавления новых официальных заклинаний создай файл в правильной папке с полями YAML `spell_level` (0–9), `spell_url`, `spell_name`, `spell_classes` (список). Скрипт подхватит файл автоматически.
