# Библиотека заклинаний D&D 5e 2014

Здесь собраны **522 заклинания** из индексного снимка **официального (не Homebrew) раздела D&D 5e 2014** сайта [dnd.su](https://5e14.dnd.su/spells/), включая PHB и официальные дополнения. Это снимок каталога, поэтому новые карточки, добавленные на сам сайт позже, могут отсутствовать.

Карточки содержат название, круг, базовые классы (если они отмечены источником) и прямую ссылку на dnd.su. Полное описание остаётся на сайте-источнике. Некоторые заклинания доступны только через подклассы/особые источники, поэтому поле классов у них может быть пустым.

## Добавление в лист персонажа

Открой лист Риас либо тестового персонажа, нажми **Добавить заклинание**, найди карточку и выбери её. **Удалить заклинание** снимает выбранную карточку из списка персонажа, не удаляя её из библиотеки.

## Свои заклинания (Homebrew)

Открой [[Заклинания/Заговоры/Заговоры|Заговоры]] или нужный круг из списка выше и нажми **Добавить своё заклинание**.
В появившейся форме укажи название, выбери один или несколько классов, школу и время накладывания, заполни дистанцию, компоненты и длительность, отметь ритуал или концентрацию и впиши описание. Можно использовать Markdown и отдельно описать усиление от круга.

После сохранения создастся **отдельный файл в папке выбранного круга**. Он автоматически появится в списке «Свои заклинания», а также станет доступен в кнопке **Добавить заклинание** у персонажа. Открой карточку и нажми **Редактировать заклинание**, чтобы исправить свойства и описание. Имя файла при редактировании заблокировано, чтобы не нарушать ссылки в листах персонажей.

Официальные заклинания остаются отдельно; их количество в старых списках не включает Homebrew. Чтобы удалить своё заклинание из библиотеки, удали его `.md`-файл в Obsidian. Перед удалением убери его из гримуаров персонажей, которые на него ссылаются.

Для добавления официальных заклинаний по-прежнему можно создать файл с полями YAML `spell_level` (0–9), `spell_url`, `spell_name` и `spell_classes`. Скрипт списка персонажа подхватит такой файл автоматически.
