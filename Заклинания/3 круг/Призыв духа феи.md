# Призыв духа феи

## Эффект

Вы призываете **фейского духа** в свободном месте в пределах **90 футов**; он сохраняется **до 1 часа при концентрации**. При создании выберите настроение — **разъярённое, весёлое или хитрое**. Оно определяет особые эффекты духа, в частности способы перемещения и воздействия на других существ. Фея дружественна группе, ходит **непосредственно после вас**, выполняет устные приказы без траты действия; без указаний уклоняется. Исчезает при 0 хитах. Для призыва нужна **позолоченная цветочная композиция стоимостью от 300 зм**, не расходуемая.

## На более высоких уровнях

При наложении ячейкой **4-го круга или выше** характеристики духа усиливаются по его **блоку статистики**.
