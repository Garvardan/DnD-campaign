# Проклятие

## Эффект

Вы касаетесь существа, которое делает **спасбросок Мудрости**. При провале оно на **1 минуту при концентрации** получает выбранное проклятие: **помеху на проверки и спасброски одной характеристики**; **помеху на броски атак против вас**; необходимость **спасброска Мудрости в начале каждого хода**, иначе цель теряет действие; либо ваши атаки и заклинания наносят ей дополнительно **1к8 некротического урона**. Мастер может разрешить другой сопоставимый вариант. **«Снятие проклятия»** прекращает эффект.

## На более высоких уровнях

Ячейка **4-го круга**: до **10 минут с концентрацией**; **5–6-го**: **8 часов без концентрации**; **7–8-го**: **24 часа без концентрации**; **9-го**: **пока не рассеяно, без концентрации**.
