# Призыв животных

## Эффект

Вы призываете духов фей, принимающих облик зверей, в свободные видимые места в пределах **60 футов**. Выберите вариант численности: **1 зверь с ПО до 2**, **2 с ПО до 1**, **4 с ПО до 1/2** или **8 с ПО до 1/4**; конкретные характеристики существ определяет мастер согласно выбранному варианту. Они дружественны вам, получают свою инициативу и выполняют устные приказы без вашего действия. Без приказов защищаются. Исчезают при **0 хитах** либо по окончании **концентрации (до 1 часа)**.

## На более высоких уровнях

При ячейке **5-го круга** число существ удваивается, **7-го — утраивается**, **9-го — учетверяется**.
