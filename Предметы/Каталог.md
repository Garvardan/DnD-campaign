Новые карточки создаются в папке `Предметы`. Открой карточку и нажми **Добавить персонажу**, чтобы выбрать владельца.

```dataviewjs
const items = dv.pages('"Предметы"')
    .where(p => p.file.path !== "Предметы/Каталог.md" && p.file.path !== "Предметы/README.md")
    .sort(p => p.file.name, "asc");
if (!items.length) {
    dv.paragraph("_Папка предметов пока пуста._");
} else {
    const rows = [];
    for (const item of items) {
        let type = String(item.item_type ?? "");
        let rarity = String(item.item_rarity ?? "");
        if (!type || !rarity) {
            const file = app.vault.getAbstractFileByPath(item.file.path);
            if (file && file.extension === "md") {
                const body = await app.vault.cachedRead(file);
                if (!type) type = String(body.match(/^Тип:\s*(.+)$/m)?.[1] ?? "").trim();
                if (!rarity) rarity = String(body.match(/^Редкость:\s*(.+)$/m)?.[1] ?? "").trim();
            }
        }
        rows.push([item.file.link, type || "—", rarity || "—"]);
    }
    dv.table(["Предмет", "Тип", "Редкость"], rows);
}
```

Старые карточки, такие как **Дюрандаль**, сохраняют исходное оформление и редактируются обычным редактором Markdown в Obsidian. Новые карточки можно редактировать через специальную кнопку.
