Личный канал: `INPUT[toggle:private_roll]`

`INPUT[imageSuggester(optionQuery("Портреты")):portrait]`

Имя: `INPUT[text:character_name]`





Бонус мастерства: `INPUT[number:prof]`
HP: `INPUT[number:hp]`
MAX HP: `INPUT[number:max_hp]`

СИЛА: `INPUT[number:str]` МОД: `VIEW[floor(({str}-10)/2)][math:str_mod]` 
```meta-bind-button
style: primary
label: Проверка
action:
  type: js
  file: Scripts/rolltodiscord.js
  args:
    name: "Проверка силы"
    formula: "1d20 + str_mod"
```
Владение спасом СИЛ: `INPUT[toggle(offValue(0), onValue(1)):str_save_prof]`
```meta-bind-button
style: primary
label: Спасбросок
action:
  type: js
  file: Scripts/rolltodiscord.js
  args:
    name: "Спасбросок силы"
    formula: "1d20 + str_mod + str_save_prof * prof"
```
